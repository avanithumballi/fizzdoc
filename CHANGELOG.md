# Changelog

## 1.0.0 — 2026-09-26

First public release.

- **44 tools** that run entirely in the browser:
  - **PDF:** edit text in place, compress, merge, split, extract and reorder pages, rotate, delete pages, add page numbers, watermark, unlock, protect with AES-256, remove metadata, and OCR into a searchable PDF.
  - **PDF conversions:** PDF to Word, PowerPoint, JPG, PNG, text and Markdown; JPG, PNG, text and Markdown to PDF.
  - **Word, Excel and PowerPoint:** Word to PDF, Excel ↔ CSV, and compress, remove metadata and extract images for .docx, .xlsx and .pptx (Google Docs, Sheets and Slides downloads included).
  - **Images:** compress, resize up or down, convert between JPG, PNG and WebP, and image to text with Live Text-style selection.
- **16 languages:** English, Hindi, Bengali, Marathi, Tamil, Telugu, Spanish, Portuguese, French, German, Italian, Dutch, Polish, Turkish, Indonesian and Vietnamese, each with its own search-optimized pages.
- **Private by construction:** no upload endpoint, a Content Security Policy that blocks every other origin, and browser tests that fail if any request leaves the page.
- Light and dark themes, per-format colours, and an interactive architecture map.
